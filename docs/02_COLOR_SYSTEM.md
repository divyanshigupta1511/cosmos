# Cosmos BrandFlow — Color System

## 1. Color Philosophy

The Cosmos BrandFlow color system represents a premium, futuristic, and elegant digital experience.

The purpose of this color system is to create a visual identity that feels:

- Premium
- Modern
- Trustworthy
- Futuristic
- Creative
- Sophisticated

The color palette combines deep space-inspired tones with elegant purple gradients and clean white elements.

---

# 2. Primary Brand Colors

## Space Black

Purpose:

- Main website background
- Hero sections
- Premium dark layouts
- Deep visual surfaces

Usage:

Creates a luxurious and immersive atmosphere.

---

## Deep Purple

Purpose:

- Brand accents
- Gradient backgrounds
- Highlight areas
- Interactive elements

Usage:

Adds creativity, innovation, and premium visual depth.

---

## Royal Purple

Purpose:

- Primary CTA buttons
- Important highlights
- Active states
- Brand emphasis

Usage:

Should be used carefully to attract attention.

---

## Pure White

Purpose:

- Main text
- Clean surfaces
- Contrast elements

Usage:

Provides clarity and improves readability.

---

## Soft Gray

Purpose:

- Secondary text
- Supporting information
- Muted UI elements

Usage:

Creates hierarchy without reducing elegance.

---

# 3. Color Usage Rules

Colors should be used intentionally.

Avoid:

- Excessive bright colors
- Random gradients
- Low contrast combinations
- Heavy visual noise

Maintain:

- Strong contrast
- Clear hierarchy
- Premium appearance
- Consistent branding

---

# 4. Gradient System

Gradients are an important part of the Cosmos visual identity.

Recommended gradient style:

- Smooth
- Subtle
- Premium
- Space-inspired

Recommended uses:

- Hero backgrounds
- CTA buttons
- Feature highlights
- Decorative elements
- Premium cards

Gradient examples:
Deep Purple → Royal Purple

Purple → White Glow

Space Black → Purple Accent

Gradients should enhance the design, not overpower the content.

---

# 5. Glassmorphism System

Glassmorphism should create a futuristic and premium feel.

Use:

- Transparent dark surfaces
- Soft blur effects
- Subtle borders
- Light reflections
- Purple tinted overlays

Glass elements should maintain:

- Good readability
- Clear spacing
- Minimal visual distraction

---

# 6. Glow Effects

Glow effects should be elegant and controlled.

Use glow for:

- Buttons
- Important cards
- Interactive elements
- Decorative animations

Rules:

- Keep glow soft.
- Avoid excessive neon effects.
- Maintain luxury aesthetics.

The glow should feel like a premium digital environment, not a gaming interface.

---

# 7. Typography Colors

## Primary Text

Use:

- White
- Near white tones

For:

- Headings
- Important information
- Main messages

---

## Secondary Text

Use:

- Soft gray tones

For:

- Descriptions
- Supporting content
- Additional details

---

## Accent Text

Use:

- Purple gradients
- Brand highlight colors

For:

- Important words
- Calls to action
- Brand emphasis

---

# 8. Button Color System

## Primary Button

Style:

- Purple gradient background
- White text
- Soft glow
- Smooth hover animation

Used for:

- Main CTA
- Important actions

---

## Secondary Button

Style:

- Transparent background
- Subtle border
- White or gray text

Used for:

- Secondary actions
- Navigation buttons

---

# 9. Accessibility Rules

The color system must maintain accessibility standards.

Always ensure:

- Text has enough contrast.
- Buttons are clearly visible.
- Important information is not dependent only on color.
- Interactive elements have clear states.

---

# 10. Design Goal

The Cosmos BrandFlow color system should create an experience that feels:

- Like a premium technology brand
- Like a modern luxury agency
- Like a futuristic digital universe

Every color choice should support trust, creativity, and elegance.
