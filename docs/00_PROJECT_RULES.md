# Development Workflow

For every development task:

1. Explain what will be changed.
2. Mention affected file paths.
3. Make only required modifications.
4. Test the changes.
5. Explain the final result.
6. Provide a recommended Git commit message.

---

# Git Commit Convention

Use professional commit prefixes:

- `feat:` → New feature
- `fix:` → Bug fix
- `style:` → UI or styling changes
- `docs:` → Documentation changes
- `refactor:` → Code structure improvements
- `perf:` → Performance improvements

Examples:

```text
feat: add hero section

fix: improve navbar responsiveness

style: update brand gradient system

docs: update project rules

refactor: organize component structure

perf: optimize animation performance
